## Orchestration and ownership

Use SKILL.md for the severity/confidence rubric and the orchestrator skill for delegation mechanics.
This checklist defines review-specific ownership only; it does not define another agent framework.

- Build the section/block index, number ledger, citation inventory and project-sourced decision list
  once. Keep those inputs read-only for independent review workers.
- Consistency needs a whole-document ledger, including the supplement. Splitting it by section
  prevents detection of cross-section contradictions.
- Soundness can split by logical section; give each worker the relevant slice, shared evidence and
  enough project context to test the claims it owns.
- Literature can split by independent citation or small batches, with one owner of bibliography
  hygiene and source acquisition. Respect the available worker and cost limits.
- The parent merges by document, anchor block and underlying issue. One defect has one owner:
  Consistency for internal disagreement, Soundness for unsupported inference, Literature for source
  fidelity. Cross-list other lenses without emitting duplicate comments.
- Main/supplement share reconciliation evidence but keep distinct anchors and output files.
- Report missing coverage, unavailable sources and interrupted workers explicitly. Sequential review
  is valid and often sufficient. A successful worker exit does not establish manuscript coverage.
- Close only after each block/section has a recorded verdict, load-bearing citations have ledger
  verdicts, findings are merged, outputs reconcile and source artifacts remain unchanged.
