## Result and ownership

The source fixes establish one owner per concern. Global instructions route; agentic-rules owns
engineering procedures; projects own facts, contracts, tests and delivery commands. Shared skills
specialize that doctrine. CLI programs perform operations, MCP exposes structured capabilities, and
plugins distribute selected provider capabilities. Provider-specific metadata is not authority.

All local harnesses link to the same 25 personal and eight engineering skill sources. Claude's
duplicate playbook plugin is disabled. Runtime settings are generated real files, policy-owned keys
win, unknown provider fields survive locally, and unsupported portable MCP shapes fail validation.
The global map no longer leaks dotfiles project rules through a home-directory AGENTS.md.

Treehouse owns agent worktrees; Herdr owns visible sessions. A task selects the active harness,
FirstMate or GNHF as its supervisor. GNHF requires an isolated retained lease and finite iteration
limit, with explicit execution flags, the intended committed starting revision and no default push.
no-mistakes consumes project-local delivery opt-in. There is one local/CI platform test entrypoint.

Memory has three deliberate destinations: Zettelkasten for crystallized insight, project Markdown
for project facts, and SQLite for captured events. Native run logs remain with their runtime owner.
Every capture field is screened for credential-shaped content; project files cannot escape the root.
